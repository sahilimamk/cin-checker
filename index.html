How to read a CIN, in 30 seconds

A CIN is 21 characters, in six parts. Read it left to right and it tells you whether the company is listed, what it does, where it is registered, when it started, what kind of company it is, and its registration number.

Char 1L

Listed or unlisted. L = listed, U = unlisted.

Chars 2–617110

Industry code — the NIC code for its main activity.

Chars 7–8MH

State of the registered office — MH is Maharashtra.

Chars 9–121973

Year of incorporation.

Chars 13–15PLC

Company type — PLC is a public limited company.

Chars 16–21019786

Registration number given by the Registrar of Companies.

So L17110MH1973PLC019786 reads: a listed public limited company, registered in Maharashtra in 1973. An LLPIN is different and much shorter — AAB-1234 is 3 letters, a hyphen and 4 digits — and it encodes no state, year or activity at all.

Two traps this checker is built to catch: PLC does not mean listed — a public company can be unlisted (its CIN starts with U), and O is not 0 — a scanned letterhead often turns a zero into the letter O. Where a single O-to-0 fix makes a number valid, the result says so.

Questions, answered plainly

Does a “Valid” result mean the company is real and active?

No. It means the number is well formed — the right length, a real state code, a real company-type code, a plausible year. A made-up number can pass a format check. Only the MCA master-data record shows whether the company exists, its status and its filings.

What does the industry code mean?

It is a 5-digit NIC (National Industrial Classification) code for the company’s main activity when it was registered. For older companies it may not describe what the business does today. This page labels only code 72900, which sources agree on; for other codes it shows the number and does not guess the activity.

Why does an LLPIN tell me so little?

Because that is all it contains: a 3-letter registry series and a 4-digit serial. State, year and activity are not encoded in it. You need the LLP’s MCA master-data record for those.

Is my list sent anywhere?

No. All checking runs in JavaScript in your browser. There is no account, no upload and no log of what you paste.

What if a number changed — for example, the company listed?

The CIN changes when listing status, state or company type changes, so an old document can carry an old CIN. If a number fails here but looks right on an old letterhead, check the current CIN on MCA.
